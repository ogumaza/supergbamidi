This release converts music from every supported driver found in a game. It
adds four games using Nintendo's MusicPlayer2000 (MP2K): *The Legend of
Zelda: The Minish Cap*, *Kingdom Hearts: Chain of Memories*, *Super Robot
Taisen: Original Generation 2* and *Golden Sun: The Lost Age*, which uses
Camelot's modified driver. It also adds Brownie Brown's driver in *Sword of
Mana* and *Magical Vacation*. MIDI output from all drivers now follows the
song's beat; use `--frame-timing` to keep events on the frames where the
game plays them. supergbamidi converts Game Boy Advance music to MIDI and
SoundFont, supporting Konami's, Rare's, Quintet's, Nintendo R&D2's and
Brownie Brown's drivers, and MP2K.

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more `.gba`,
`.gsflib` or `.minigsf` files on `supergbamidi.exe`, or run it in a terminal; `supergbamidi --help`
lists the options. Each file's output goes in a folder next to it.

For macOS and Linux, follow the build instructions in the README. On macOS the build also makes
`Supergbamidi.app`, which you can drop files on in the Finder.

## Changes since 1.2.0

- Games with multiple drivers now have every driver's songs converted. *The Legend of Zelda: A Link
  to the Past & Four Swords* therefore includes the menu and *Four Swords* music alongside *A Link
  to the Past*. The first driver detected keeps the usual file names; the others add their driver's
  name after the base name, as in `game_mp2k_000.mid`. Messages include the driver before the song
  number. `--driver` selects one driver and uses the usual file names. `--trace` uses the first
  driver, as do `--song-table` and `--song-count` when given without `--driver`.
- MP2K is found in games whose compiler built the routine that starts a song with two registers
  swapped, such as *The Minish Cap*, *Chain of Memories* and *Original Generation 2*, and `--info`
  says when a game's mixer is mono.
- Camelot's version of MP2K, in *Golden Sun: The Lost Age*, is converted as the game plays it: its
  choice of channels, its volumes and rates, its mixer's straight-line releases, and its synth
  voices, a pulse wave whose duty moves up and down each frame, a saw wave through a filter, and a
  triangle wave. The SoundFont plays a pulse or saw voice with a sample made for each key a song
  plays it at. The mixer's echo, which is the same in every song, becomes a reverb send.
- Brownie Brown's driver in *Sword of Mana* is now supported, including the sound effects listed
  alongside the music in its song table. The music uses PSG channels with software and hardware
  envelopes, and five sample channels. The mixer uses sets containing a sample for each semitone.
  The SoundFont preserves the game's tuning. Select the driver with `--driver brownie` and choose
  among its 13 channels with `--tracks`.
- The older Brownie Brown driver in *Magical Vacation* is also supported. It has 12 channels and
  plays samples directly through the FIFOs, one sample per FIFO. The driver sets each note's rate in
  12ths of a semitone, and the SoundFont tunes each sample key to that rate.
- MIDI files from Konami's and Brownie Brown's drivers put each note on the song's beat, as the other
  drivers' always have, so that they line up with the bars and beats in an editor. These drivers
  count time in frames, so supergbamidi works out the beat from the lengths of the notes, with its
  changes of tempo, ritardandos and rubatos, and moves each note onto it if it's within a frame and a
  half. A part that plays behind the others, as an echo does, keeps its delay. The MIDI files have
  480 ticks per quarter note.
- `--frame-timing` puts each event on the frame the game plays it in, rather than on the song's beat,
  with any of the drivers.
- Loop markers now reproduce the game's playback more closely in some songs. When the loop sets a
  track's program, volume, pan, expression, reverb or pitch bend, the MIDI file repeats that setting
  even if its value hasn't changed. This prevents a looping player from retaining the value from the
  end of the loop. For Quintet's and Brownie Brown's drivers, the marked loop starts on the second
  pass if the first sounds different, for example because the intro leaves a different octave
  setting.
- MP2K detection now skips song-table entries zeroed out by a GSF rip and finds the songs after
  them. Previously, the song list stopped at the first empty entry.
- MP2K PSG notes now keep their pitch during release. The driver applies bend and tuning to noise
  notes in discrete steps, and limits square and wave notes to a minimum pitch of C2. The MIDI pitch
  bend already followed these rules while a note played, but previously reverted to the track's
  pitch at note-off, causing the release to rise or fall in pitch.

## Known limitations

- With MP2K, when a track changes its volume, pan or pitch in the tick in which it starts a note,
  the driver gives the change to the new note alone, but the MIDI file changes the track's older
  notes as well. In a game whose mixer is mono, every DirectSound note plays in the middle, while
  the MIDI file keeps each track's pan.
- In *Golden Sun: The Lost Age*, a pitch bend speeds up or slows down a pulse wave's changing duty
  and changes a saw wave's filter a little, where the game keeps them as they are, and the reverb
  send only approximates the mixer's echo.
- In *Sword of Mana* and *Magical Vacation*, the hardware's envelope can step up to a frame later
  than in the game, and a sound effect plays on its own, where in the game it takes its PSG channel
  from the music.
- The limitations listed for 1.2.0 still apply. See "Accuracy" and "Known issues" in the README for
  the details.
