This release adds support for *Digimon Racing*, which uses Krawall to play
XM and S3M modules; *Super Mario Advance 2: Super Mario World*, which uses
an older revision of Nintendo R&D2's driver; and *Donkey Kong Country 3*,
which uses a later revision of Rare's driver. supergbamidi converts Game Boy
Advance music to MIDI and SoundFont, supporting Konami's, Rare's, Quintet's,
Nintendo R&D2's and Brownie Brown's drivers, MP2K and Krawall.

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more `.gba`,
`.gsflib` or `.minigsf` files on `supergbamidi.exe`, or run it in a terminal; `supergbamidi --help`
lists the options. Each file's output goes in a folder next to it.

For macOS and Linux, follow the build instructions in the README. On macOS the build also makes
`Supergbamidi.app`, which you can drop files on in the Finder.

## Changes since 1.3.0

- Krawall, Sebastian Kienzl's XM and S3M player, is supported in its 2003/09/01 build, used by
  *Digimon Racing*. Each module becomes a MIDI file with a track per channel and a SoundFont
  containing the samples it plays. The converter chooses a beat whose tempo is between 105 and
  210 BPM, using 4/4 or 12/8 according to how the patterns fit. Bars follow pattern boundaries.
  Volume and pan changes, envelopes and slides become CC11 and CC10; portamentos, vibratos and
  arpeggios become pitch bends. Loops are detected when playback returns to an earlier position.
  Games with a later Krawall build get an error naming the build.
- *Super Mario Advance 2: Super Mario World* is supported, with an older revision of Nintendo R&D2's
  driver than *A Link to the Past*'s. Its bends, levels, mix and tempo command differ, and the
  conversion follows the game's. Notes on an instrument or drum that a bank doesn't have, which the
  game never sounds, are left out with a warning.
- *Donkey Kong Country 3* is supported, with a later revision of Rare's driver, in which a tune can
  set the attack, decay, sustain and release of a channel's notes in place of their instrument's. A
  note that plays with such settings gets a preset with the same program number in a bank of its
  own, which the MIDI file selects before the note.

## Known limitations

- With Nintendo R&D2's driver, a track that plays a key twice at once is one MIDI note, up to 6 dB
  quieter than in the game, and a sequence whose tracks the game mutes when it plays it, as *Super
  Mario Advance 2* does to choose between two endings of a jingle, has every track in the MIDI file.
- With Krawall, a module that the game plays once, as a jingle, loops like the others, since
  nothing in the module says how the game plays it, and the conversion plays each module at the
  music volume that the library starts with.
- *Donkey Kong Country 3* can fade channels out and start a tune partway through, at a marker. The
  conversion plays each tune from its start, with every channel at its own volume.
- The limitations listed for 1.3.0 still apply. See "Accuracy" and "Known issues" in the README for
  the details.
